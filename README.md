# Монитор энергосети

`energy.lua` работает в OpenComputers и использует `average_counter.getAverage()`, как исходная версия. Все значения — EU/t. Нужны GPU и экран с разрешением минимум 60×22. На одном экране показаны пять категорий, общая выработка, общий расход, баланс и график выработки. На широком экране (от 100 столбцов) добавлены среднее за время работы и число доступных счётчиков.

## Настройка

1. Подключите отдельные `average_counter` на линиях генераторов и потребителей. Один счётчик может измерять всю категорию или отдельную независимую ветку. Единственный общий счётчик не позволяет разделить поток по типам устройств.
2. Выполните `energy.lua --list`, чтобы увидеть адреса счётчиков. Для определения соответствия линиям подключайте счётчики по одному и повторяйте команду.
3. Положите `energy-config.lua` рядом с `energy.lua` и заполните его своими адресами:

   ```lua
   return {
     reactors = {"адрес-счётчика-реакторов"},
     solar = {"адрес-счётчика-солнечных-панелей"},
     wind = {"адрес-счётчика-ветрогенераторов"},
     molecular = {"адрес-счётчика-преобразователя"},
     machines = {"адрес-счётчика-механизмов"},
     updateInterval = 0.5
   }
   ```

   Можно использовать уникальное начало адреса и перечислить несколько счётчиков через запятую. Их показания суммируются. Не привязывайте один счётчик к нескольким категориям. Не суммируйте общий счётчик линии со счётчиками её ответвлений: это даст двойной учёт. Счётчик механизмов должен измерять расход без преобразователя, если преобразователь уже измеряется отдельно. Показания обоих типов потоков ожидаются положительными, как в исходной программе; отрицательные значения отмечаются как ошибка чтения.

4. Запустите `energy.lua`. Настройки загружаются из папки программы, даже при запуске из другой папки. Можно указать другой файл: `energy.lua /home/my-config.lua`. После изменения настроек перезапустите монитор. Для выхода нажмите Q или Ctrl+C. Исходные разрешение и цвета экрана восстанавливаются.

Поиск папки программы использует [Process API](https://ocdoc.cil.li/api:process) и [Filesystem API](https://ocdoc.cil.li/api:filesystem) OpenOS. `energy.lua --list` работает и без файла настроек.

Если настройка пустая и подключён ровно один счётчик, он отображается как реакторы для совместимости. При нескольких счётчиках нужна явная привязка. Список устройств обновляется каждый цикл, поэтому после восстановления соединения показания возвращаются автоматически.

## Значения на экране

- **Общая выработка** — сумма реакторов, солнечных панелей и ветрогенераторов.
- **Общий расход** — сумма преобразователя и механизмов.
- **Баланс** — выработка минус расход; показывается только при наличии данных всех пяти категорий.
- **`~`** — сумма только доступных настроенных счётчиков. Это неполные данные.
- **«не настроено»**, **«нет связи»**, **«ошибка чтения»**, **«неоднозначный адрес»** — отсутствие достоверных показаний, а не нулевая мощность.
- Среднее и пик учитывают только полные успешные измерения. При неполных данных выработки в графике остаётся разрыв.

Если категория физически отсутствует, оставьте её пустой: она будет отмечена как ненастроенная, сумма — как неполная, а баланс не будет рассчитан.
